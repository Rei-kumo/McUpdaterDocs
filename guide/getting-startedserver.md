# 快速开始

本文档将引导你快速完成服务端基本配置。

## 一、下载文件

安装需要服务端，提供两种下载方式

- 从 [Releases](https://github.com/Rei-kumo/McUpdaterserver/releases) 页面下载最新版本的程序包
- 从 [iPan](https://pan.reikumo.cn/s/y4HW) 页面下载最新版本的程序包

两种方式任选其一即可，Releases 为 GitHub 官方源，iPan 为国内镜像站（速度更快）。

将下载得到的exe程序放置到想要放的地方，最好新建一个文件夹，因为启动后会创建配置文件夹等工作目录。
## 二、启动服务端

首次运行服务端前，需要生成配置文件。

1. 在服务端目录下，直接双击运行McUpdaterServer.exe。
2. 第一次运行程序**自动退出**，这个时候，程序已经自动创建了 config/server.json 以及必要的目录结构（public, updates等）。  
## 三、放入要更新的文件

:::warning 注意：版本隔离
如果你的整合包开启了版本隔离（如 PCL2、HMCL 的“版本独立”功能），模组文件夹位置会变为：
`.minecraft/versions/<你的整合包名>/mods/`

此时 public/ 目录应模拟这个结构：
```
public/
└─ .minecraft/
    └─ versions/
        └─ abc/          # abc 是你的整合包名称
            └─ mods/
```
:::

将你需要分发的所有文件复制到服务端目录下的 public/ 文件夹中，以下提供几种常见的。

::: code-group

```text [同步模组]
把你想要同步的新版.minecraft/mods目录复制，然后粘贴到下public目录下。
.minecraft目录需要你手动创建，注意：public目录对应玩家启动器所在的位置（如果你没有修改客户端配置的话）

目录结构像这样：

存放McUpdaterServer.exe的文件夹/ 
└─ public/
  └─ .minecraft/
    └─ mods/（整个粘贴过来，当然也可以把mod丢进去，总之这里面长什么样客户端就会长什么样）

```

```ts [更新其他文件]
有的时候可能想要同步点其他文件，比如说配置，一些资源文件之类的，那么类似模组的更新。

我们假如想给玩家更新个材质包，就应该在public目录下准备一个.minecraft/resourcepacks,这样子这个文件夹就会跟服务器同步
目录结构像这样：

存放McUpdaterServer.exe的文件夹/ 
└─ public/
  └─ .minecraft/
    └─ resourcepacks/ //在这里放入材质包

抑或是你只想更新一个文件，比如你想在启动器旁边放一个1.txt，那你直接在public目录下放一个就行。

总而言之,public 目录下与玩家的客户端是映射的，你放什么玩家对应的东西就会被同步。


```

:::

## 四、打包（生成第一个版本）

首次生成版本需要扫描 public/ 并创建全量包。
- 为了快速简单,我们不使用命令行，直接双击运行 McUpdaterServer.exe即可。
- 你应该能看到命令行窗口的输出长这样：
```text
[INFO]=== McUpdaterServer 日志开始 ===

===== Minecraft更新服务器菜单 =====
1. 启动Web服务器
2. 扫描工作空间
3. 创建新版本
4. 初始化配置
5. 显示帮助
6. 重置版本系统
7. 回退到指定版本
8. 退出
==================================
工作空间: ./public
请选择操作 (1-8):
```
- 我们键入数字3，然后回车，程序会提示你输入版本号：
```text
请选择操作 (1-8): 3
请输入版本号:

```
- 这个时候按照x.x.x的格式随便输入就行了。

成功后你会看到类似输出：

```text
[INFO] 版本 1.0.0 创建完成!
```
:::tip
其中 1.0.0 为版本号，必须符合 x.x.x 格式（如 1.0.0, 2.3.1）。
:::
## 五、启动服务端
在版本创建后回车回到主菜单，输入数字1启动Web服务器，如果已经关掉，也可再次双击启动。

看到以下输出表示启动成功：

```text
[INFO] Web服务器启动于 http://0.0.0.0:8080
```
现在服务端已就绪，客户端可以通过 http://你的IP:8080 访问更新 API。

::: warning
**不要在打包过程中关闭窗口！** 打包（创建版本）期间强制关闭可能导致版本数据损坏。请在打包完成后再停止服务端。
:::
