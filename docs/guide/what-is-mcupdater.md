# McUpdater 是什么？

McUpdater 是一个轻量级的 Minecraft 客户端文件同步工具，由**服务端**和**客户端**两部分组成。

- **服务端**（McUpdaterServer）：负责存放待分发的文件、管理版本、提供 HTTP API 和下载服务。
- **客户端**（McUpdaterClient）：负责访问服务端 API，比对本地文件，下载缺失或更新的内容。

McUpdater 不仅限于 Minecraft，你可以将它用于任何需要文件同步的场景。

## 核心特性

- **增量更新**：只下载变化的部分，节省带宽和时间
- **哈希校验**：精确识别文件变更，确保一致性
- **启动器自更新**：客户端可以自行更新自身
- **双模式支持**：版本号模式（简单）和哈希模式（精确）
