# 快速开始

本文档将引导你快速完成客户端基本配置，在观看此教程前，应先完成服务端的配置，并且记住服务端的api。

## 一、下载文件

- 从 [Releases](https://github.com/Rei-kumo/McUpdaterClient/releases) 页面下载最新版本的程序包：
- 从 [iPan](https://pan.reikumo.cn/s/y4HW) 页面下载最新版本的程序包

两种方式任选其一即可，Releases 为 GitHub 官方源，iPan 为国内镜像站（速度更快）。

将下载得到的exe程序放置到想要放的地方，一般是启动器所在目录，启动后会创建配置文件夹等工作目录。
## 二、配置客户端

首次运行客户端前，需要生成配置文件。

1. 在客户端目录下（即你放置 McUpdaterClient.exe 的文件夹），直接双击运行。
2. 第一次运行程序会动退出，这个时候，程序已经自动创建了 config/updater.json 作为配置文件。  
## 三、修改配置文件

用记事本或者任何文本工具打开updater.json。

配置文件示例：
```json
{
  ...
  "update_url" : "https://your-server.com/updates/version.json", // [!code focus]
  ...
}
```
如上所示，为了快速部署，我们只需要关注代码中高亮的部分，其他配置保持默认即可。
- 首先检查是否保存了刚才服务端输出的ip及端口，通常来说你会得到http://127.0.0.1:8080。
- 这个地址是本地地址，只能由你本地的人访问，为了让你的玩家能访问到你的服务器，你需要拥有一个ipv4公网ip。
- 如果你是vps直接放通即可，对于在自己电脑搭建的，一般没有vps，那么就仿照放通minecraft25565端口的方式把8080端口放通即可。
- 对于本教程中，我们使用的是内置web服务器，所以填入http://公网ip:8080/api/update 即可，完成后保存。
::: tip
在本教程中，不会教学如何开放公网网口，有可能的话我们将会在其他章节及讲到。
:::
## 四、打包

完成配置后，客户端的配置已经完成。

- 如果不是在客户端根目录（启动器所在地）配置的，那么，请将McUpdaterClient.exe和config拖到客户端打包后分发即可。

- 在正式分发给玩家前，建议发给朋友测试一下，以免配置异常，如果一切正常，快速开始的教程已经结束，进阶玩法请看其他章节。
